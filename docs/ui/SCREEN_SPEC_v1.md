# Screen Specification v1.0

## Global shell
- Desktop: fixed sidebar + top utility bar + scrollable content.
- Mobile: compact header + bottom navigation + sheets.
- Workspace context is always visible or one tap away.

## 01 Dashboard
Purpose: orient user in under 5 seconds.
Primary CTA: add funds / start AI / browse services depending on context.
Hero content: wallet, active work, AI usage.

## 02 AI
Purpose: execute AI tasks with minimal friction.
Required: model/context visibility, usage, files, history, saved outputs.

## 03 Social
Purpose: discover and purchase social services.
Required filters: platform, category, price, speed, quality/status.

## 04 Automation
Purpose: create and monitor workflows.
Required: trigger → steps → test run → publish → run history.

## 05 Orders
Purpose: track every order.
Required statuses, timeline, retry/refund information when authorized.

## 06 Wallet
Purpose: make money movement understandable.
Required: balance, ledger, payments, invoices, refunds.

## 07 Analytics
Purpose: show business performance without clutter.
Required: revenue, cost, margin, usage, conversion, order performance.

## 08 Settings
Purpose: identity, security, workspace, API keys, notifications and integrations.

## 09 Admin/Ops
Separate privileged area. Provider health, queues, failures, fraud/risk, audit, reconciliation.
