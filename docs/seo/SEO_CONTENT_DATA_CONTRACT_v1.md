# SEO/GEO Content Data Contract v1

Every indexable public entity must have one canonical source record containing:
- stable slug and canonical URL
- human-readable title and description
- audience
- capabilities
- requirements
- pricing model/reference
- limitations
- update/review date
- category and relationships

## Rules
1. Visible content and structured data must describe the same facts.
2. Prices, limits, availability and capabilities must come from application source-of-truth when dynamic.
3. Private/authenticated routes are noindex.
4. Public pages must render the core factual answer server-side.
5. No doorway pages, keyword stuffing, hidden text, fake reviews or fabricated evidence.
6. Every generated route must have a deterministic canonical URL.
7. New content types require a schema contract before implementation.
8. If a claim cannot be supported by first-party data or an explicitly attributed source, do not present it as a platform fact.

## Future content types
Service, AI Product, Social Channel, Use Case, Article, FAQ, Documentation, API Reference, Comparison, Policy, Glossary.
