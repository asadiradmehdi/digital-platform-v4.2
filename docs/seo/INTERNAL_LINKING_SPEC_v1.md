# Internal Linking Spec v1

Public content should form a deliberate information architecture rather than isolated landing pages.

## Required link directions
- Pillar -> category -> product/service
- Product -> related products
- Product -> relevant use cases
- Product -> FAQ/reference content
- Article -> canonical product/service where relevant
- Category -> pricing and support

## Anchor text
Use descriptive, natural Persian or English anchor text. Avoid repeated exact-match anchors solely for search-engine manipulation.

## Orphan control
Every indexable page must be reachable from at least one canonical hub or sitemap entry. Before launch, run an automated orphan-page check over the public route manifest.
