# Programmatic SEO Rules v1

Programmatic public pages are allowed only when each URL represents a real, useful entity or use case.

## Allowed dimensions

- Service category
- Social channel
- AI capability
- Workflow/use case
- Region/language when there is genuinely localized content

## Forbidden combinations

Do not generate every possible permutation of category × channel × city × keyword unless a real page exists for that combination.

## Uniqueness gate

A generated page must have materially unique:

- user intent
- explanation
- requirements
- examples
- structured data
- internal links
- canonical URL

Otherwise consolidate into a parent page.

## Indexability

Generated pages must pass the same SEO/GEO QA as hand-authored pages.
