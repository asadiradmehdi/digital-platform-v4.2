# Visual Direction v4.0 — Persian Premium Product

## هدف
رابط کاربری باید برای کاربر ایرانی، فارسی‌محور، ممتاز، سریع و قابل اعتماد باشد؛ نه ترجمه‌ی یک داشبورد خارجی.

## اصول
- Dark Obsidian به‌عنوان پایه
- Violet/Aurora فقط به‌عنوان Accent و Signal
- Cyan بسیار محدود برای اطلاعات ثانویه
- فضای خالی زیاد و سلسله‌مراتب روشن
- کارت کمتر، اطلاعات با ارزش بیشتر
- بدون Glassmorphism افراطی، Gradientهای تزئینی یا شلوغی
- RTL واقعی؛ متن لاتین و اعداد با isolate و font مناسب
- Mobile یک محصول Native است، نه نسخه‌ی کوچک‌شده‌ی Web
- همه‌ی صفحات باید از همان Tokenها و Primitiveها استفاده کنند

## Quality Bar
اگر یک صفحه شبیه Admin Template عمومی، شلوغ، براق یا وابسته به متن انگلیسی باشد، رد است.

## Claude Rule
هر UI جدید باید از Design System استفاده کند و هیچ رنگ، spacing، radius یا typography مستقل و خارج از Tokenها اضافه نکند مگر با ثبت تصمیم طراحی.
