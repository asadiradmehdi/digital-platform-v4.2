# Prepare and run the project autonomously

Read `/docs/handoff/CLAUDE_HANDOFF.md` and `/docs/handoff/OWNER_HANDOFF.md`.

Then:
1. Run `./scripts/doctor.sh`.
2. If dependencies are absent and network access is available, run `./scripts/bootstrap.sh`.
3. Read `CLAUDE.md`, the master blueprint, architecture, database, API, security, UI specs, autonomous plan and task ledger.
4. Continue from the first incomplete task using the `/continue` procedure.
5. Do not ask routine implementation questions.
6. Do not advance a stage without a green stage gate.
